## Épica 1: Gestión de usuarios

### Feature 1.1: Registro
- US-01: Como usuario quiero registrarme para poder utilizar la plataforma.
- US-02: Como usuario quiero recuperar mi contraseña para poder acceder nuevamente.

### Feature 1.2: Inicio de sesión
- US-03: Como usuario quiero iniciar sesión para acceder a mi cuenta.

## Épica 2: Catálogo de productos

### Feature 2.1: Catálogo
- US-04: Como usuario quiero visualizar productos para conocer las opciones disponibles.
- US-05: Como usuario quiero buscar productos para encontrar rápidamente lo que necesito.

### Feature 2.2: Filtros y detalle
- US-06: Como usuario quiero filtrar productos por categoría y talla para ver solo las prendas que me interesan.
- US-07: Como usuario quiero ver el detalle de un producto para conocer sus características, colores y precio.

## Épica 3: Carrito de compras

### Feature 3.1: Gestión del carrito
- US-08: Como cliente quiero agregar productos al carrito para reunir lo que deseo comprar.
- US-09: Como cliente quiero modificar o eliminar productos del carrito para ajustar mi compra.

## Épica 4: Pedidos y pagos

### Feature 4.1: Pedidos
- US-10: Como cliente quiero realizar un pedido para recibir mis prendas.
- US-12: Como cliente quiero consultar mi historial de pedidos para hacer seguimiento a mis compras.

### Feature 4.2: Pagos
- US-11: Como cliente quiero pagar mi pedido en línea para finalizar la compra de forma segura.

## Épica 5: Administración de la tienda

### Feature 5.1: Gestión de productos
- US-13: Como administrador quiero crear y editar productos para mantener el catálogo actualizado.
- US-14: Como administrador quiero gestionar el inventario para saber qué prendas hay disponibles.

### Feature 5.2: Gestión de pedidos
- US-15: Como administrador quiero gestionar los pedidos para cambiar su estado y atender a los clientes.
